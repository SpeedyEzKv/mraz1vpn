# Исходники бренда «стеклянная звезда»

Рендер на numpy/scipy/Pillow, без внешних сервисов. Запуск из этой папки:

- `python3 avatar.py 11` → `avatar-11.png` (аватарка бота, 1024×1024)
- `python3 assets.py` → `banner-bg.png`, `star-hero.png`, `star-logo.png`, `liquid.jpg`
- `python3 logo.py` → `star-logo.png` (знак для шапки кабинета)
- баннер `/start`: открыть `banner.html` рядом с `banner-bg.png` и сохранить скриншот 1280×720
  в `server/assets/welcome.jpg`

Готовые картинки кабинета лежат в `web/public/brand/`.
